neural_network_framework — a deep learning framework built from scratch

A complete deep learning framework written in pure Python + NumPy, with every gradient computed explicitly — no autodiff library, no black boxes. Implements a real reverse-mode automatic differentiation engine (topological sort + gradient closures), a PyTorch-mirrored API, and every layer needed to train an actual network end to end.
